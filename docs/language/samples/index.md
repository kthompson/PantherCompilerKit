# Samples

Complete programs, each with the output it prints. Every sample here is
compiled and run by `doccheck` in CI, so the output shown is what the program
actually prints.

- **[FizzBuzz](fizzbuzz)** - Loops, conditions, and building strings
- **[Fibonacci](fibonacci)** - Recursion compared with iteration
- **[Expression Evaluator](expression-evaluator)** - Enums, pattern matching, and recursion over a tree
